# 首页 UI/UX 规范

## 布局结构

### 页面分区
```
┌─────────────────────────────┐
│         Header              │  可选：简洁导航
├─────────────────────────────┤
│                             │
│      Hero 区域              │  60vh - 100vh
│   (黑洞视觉效果 + 标题)     │
│                             │
├─────────────────────────────┤
│                             │
│    项目介绍区域              │  auto
│    (特性卡片展示)            │
│                             │
├─────────────────────────────┤
│         Footer              │  简洁版权信息
└─────────────────────────────┘
```

### 响应式断点
- **移动端**: < 768px
- **平板**: 768px - 1024px
- **桌面**: > 1024px

## 视觉设计

### 色彩方案（暗黑宇宙主题）
| 用途 | 颜色代码 | 说明 |
|------|----------|------|
| 背景主色 | #0a0a0f | 深空黑 |
| 背景次色 | #12121a | 星云灰 |
| 强调色 | #ff6b35 | 橙红（吸积盘核心） |
| 辅助强调 | #f7c948 | 金色（吸积盘外环） |
| 文字主色 | #ffffff | 白色 |
| 文字次色 | #a0a0b0 | 灰色 |
| 玻璃质感 | rgba(255,255,255,0.1) | 半透明白 |

### 字体规范
- **标题字体**: "Orbitron", sans-serif（科技感）
- **正文字体**: "Inter", "PingFang SC", sans-serif
- **字号**:
  - 主标题: 48px (移动端 32px)
  - 副标题: 24px (移动端 18px)
  - 正文: 16px
  - 辅助文字: 14px

### 视觉效果

#### 黑洞吸积盘
- **核心区域**: 径向渐变，中心亮橙色 (#ff6b35) → 边缘深红 (#8b0000)
- **旋转动画**: 顺时针/逆时针交替，周期 20s
- **粒子效果**: 漂浮光点模拟星际尘埃

#### 引力透镜效果
- **扭曲效果**: 边缘光晕向外扩散
- **光圈**: 多层半透明同心圆

#### Liquid Glass 按钮
- **背景**: 毛玻璃效果 `backdrop-filter: blur(20px)`
- **边框**: 1px 渐变边框（#ff6b35 → #f7c948）
- **阴影**: 彩色光晕投影
- **悬停**: 边框发光增强，内部亮度提升

## 组件清单

### 1. BlackHoleCanvas
- 用途：渲染黑洞吸积盘动画
- 技术：Canvas 2D / WebGL

### 2. GlassButton
- 用途：登录/注册按钮
- 属性：type (primary/secondary), to (跳转路径)

### 3. FeatureCard
- 用途：特性展示卡片
- 属性：icon, title, description

### 4. HeroSection
- 用途：主视觉区域
- 包含：BlackHoleCanvas, 标题文字, GlassButton

### 5. IntroSection
- 用途：项目介绍区域
- 包含：介绍文字, FeatureCard 列表

## 动画规范

### 页面加载动画
| 元素 | 动画 | 时长 | 延迟 |
|------|------|------|------|
| 背景 | fadeIn | 1s | 0s |
| 黑洞 | scaleIn + rotate | 1.5s | 0.3s |
| 标题 | fadeInUp | 0.8s | 0.8s |
| 按钮 | fadeInUp | 0.6s | 1.2s |

### 交互动画
| 元素 | 事件 | 动画 | 时长 |
|------|------|------|------|
| 按钮 | 悬停 | scale(1.05) + glow | 0.3s |
| 按钮 | 点击 | scale(0.98) | 0.1s |
| 卡片 | 悬停 | translateY(-8px) + shadow | 0.3s |
