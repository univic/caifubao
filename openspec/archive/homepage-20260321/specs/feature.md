# 首页功能规范

## 功能概述

首页作为 Caifubao 项目的入口页面，承担品牌展示和用户引导的功能。

## 用户交互流程

```
用户访问 → 首页加载 → 黑洞动画渲染 → 浏览内容 → 点击登录/注册 → 跳转认证页面
```

### 页面加载流程
1. 页面骨架渲染（CSS 3s 内完成）
2. 黑洞 Canvas 动画初始化（300ms 延迟）
3. 文字内容淡入（500ms 延迟）
4. 按钮交互事件绑定

## 功能模块

### 1. Hero 区域
- **黑洞视觉效果**：Canvas 绘制旋转吸积盘
- **项目 Logo/名称**：Caifubao 标题
- **副标题**：大A量化分析系统

### 2. 功能按钮
- **登录按钮**：跳转 /login
- **注册按钮**：跳转 /register
- **样式**：iOS 26 Liquid Glass 质感

### 3. 项目介绍区域
- **标题**：智能量化，洞悉市场
- **描述文字**：简洁的项目功能描述

### 4. 特性展示
- **市场总览**：实时行情数据
- **智能回测**：量化策略回测
- **信号发现**：交易信号推送

## 用户交互

| 交互元素 | 事件 | 行为 |
|---------|------|------|
| 登录按钮 | 点击 | 跳转到 /login |
| 注册按钮 | 点击 | 跳转到 /register |
| 特性卡片 | 悬停 | 放大 + 阴影效果 |
| 黑洞区域 | 鼠标移动 | 轻微视差效果 |

## 验收标准

- [ ] 页面在 2s 内完成首次内容渲染
- [ ] 黑洞动画流畅运行（60fps）
- [ ] 登录/注册按钮具有液态玻璃视觉效果
- [ ] 移动端布局正常显示
- [ ] 点击按钮正确跳转到目标页面
