# Caifubao 首页需求分析

## 背景

Caifubao 项目目前已有完整的认证系统、Dashboard、行情查询、回测系统和交易信号模块。为提升用户体验和品牌辨识度，需要设计一个全新的首页，视觉灵感来自电影《星际穿越》中的卡冈图雅黑洞。

## 变更概述

### 新增内容
- 全新设计的首页视图（HomeView）
- 基于卡冈图雅黑洞的视觉效果（吸积盘 + 引力透镜）
- iOS 26 Liquid Glass 质感的登录/注册按钮
- 响应式布局（PC + 移动端）

### 功能模块
1. **Hero 区域**：黑洞视觉效果 + 项目名称 + 登录注册按钮
2. **项目介绍区域**：简洁的功能描述
3. **特性展示区域**：核心功能亮点

## 影响

- **新增页面**: `/home` 路由
- **技术依赖**: Three.js / Canvas 2D / CSS 动画
- **样式风格**: 暗黑宇宙主题 + 液态玻璃效果
- **响应式**: 移动端适配

---

## 非目标（本次不做）

- 首页动态数据展示
- 首页国际化
- 复杂的用户交互功能（登录注册跳转到现有页面）
