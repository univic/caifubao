# Caifubao Frontend

Vue 3 + Vite + Pinia + Element Plus frontend for the Caifubao quantitative analysis platform.

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

The dev server connects to `http://api.dev.cfb.concorde102.cn` for backend APIs.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

See `docs/DESIGN.md` for the visual design system (Linear dark theme).
